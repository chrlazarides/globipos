# Decisions

One Markdown file per decision, named `YYYY-MM-DD-short-topic.md`.
Include **date** (Europe/Nicosia), **status** (proposed/accepted/superseded),
**decision**, **why**, and **alternatives considered**.
Link the approving issue/PR and any superseding decision. Never include secrets
or personal customer records. Keep historical decisions; supersede rather than
silently rewriting their approval.
