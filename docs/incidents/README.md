# Incidents

One Markdown file per incident, named `YYYY-MM-DD-short-topic.md`.
Include **date/time** (Europe/Nicosia), **what happened**, **impact**,
**fix**, and **prevention**. Link the issue/PR, supporting non-sensitive evidence,
rollback/recovery and follow-up checks.
Distinguish observations from suspected causes. Do not copy credentials, live
customer data or unredacted logs into a report.
