---
name: GlobiPOS app icon
description: Brand convention for GlobiPOS installer, launcher, taskbar, and mobile icons.
---

Use the standalone blue aperture mark from the official GlobiPOS logo for square application icons on a white background.

**Why:** The horizontal wordmark becomes too small to recognize at 16–32 px, while customer artwork must never appear as the GlobiPOS Terminal installer or launcher icon.

**How to apply:** Regenerate the complete Tauri icon set from a square, high-resolution source containing only the aperture mark whenever packaging icons are updated.
